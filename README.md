# Dilemmes Moraux

## Description
**Dilemmes Moraux** est une application web interactive qui propose des dilemmes éthiques
dans lesquels l'utilisateur doit faire un choix. Chaque décision permet d'explorer
les valeurs morales et les conséquences hypothétiques associées.

L'application fonctionne via un serveur **Node.js / Express** et une interface web simple.

## Prérequis
- Node.js 18 ou supérieur
- npm

## Installation
```bash
git clone <url-du-repo>
cd Dilemmes_moraux_V3
npm install
```

## Lancement
```bash
node index.js
```
Puis ouvrir : http://localhost:3000

- Le dossier `node_modules` ne doit pas être versionné.
- Projet idéal pour l'apprentissage des choix moraux et de JavaScript côté serveur.
